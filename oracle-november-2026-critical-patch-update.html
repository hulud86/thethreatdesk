Oracle's November patch update fixes hundreds of flaws, including Java4Shell

Oracle shipped 655 patches covering about 950 CVEs. Just over 300 can be exploited remotely without logging in, and 62 fix critical bugs. None are reported as exploited.

By The Threat DeskNovember 17, 2026

Oracle released its November 2026 Critical Patch Update on November 17 with 655 new security patches across its product line. SecurityWeek counted 948 unique CVEs in the advisory, 640 of them listed in Oracle's product risk tables; the different totals come from how bundled third-party flaws are counted.

The headline numbers

  • Just over 300 patches fix flaws that can be exploited over the network without credentials.
  • 62 patches address critical-severity bugs, including six rated at the maximum severity: five in Fusion Middleware and one in Analytics.

Where the patches landed

  • Hyperion: 267 patches, 107 of them for remote, unauthenticated bugs.
  • Supply Chain: 74, with 36 remote and unauthenticated.
  • Fusion Middleware: 71, with 53 remote and unauthenticated.
  • E-Business Suite: 71, with 19 remote and unauthenticated.
  • Communications: 31, with 21 remote and unauthenticated.
  • Java SE: 11, all remotely exploitable without login.
  • MySQL: 10 patches, plus fixes for Database Server, APEX, Enterprise Manager, REST Data Services and JD Edwards.

Java4Shell

The Java SE update includes the fix for Java4Shell (CVE-2026-114938), the memory corruption bug in Java's Base64 handling that can lead to remote code execution. The Threat Desk covered it when it was disclosed on November 18.

Exploitation

Oracle has not said any of these flaws are being exploited. That can change quickly. Oracle E-Business Suite and WebLogic have been prime targets for extortion groups, and attackers often reverse-engineer patches within days.

Who's affected

Organizations running Oracle Fusion Middleware, E-Business Suite, Hyperion, Database, MySQL, Java SE or other Oracle products.

What to do

Review the November advisory, patch internet-facing Fusion Middleware, E-Business Suite and Java SE first, and keep Oracle admin interfaces off the public internet.
