Fake Teams meeting bookings trick victims into approving attacker logins

Huntress found a phishing kit that disguises a Microsoft device sign-in code as a booking reference, so victims approve the attacker's session on Microsoft's real login page.

By The Threat DeskNovember 13, 2026

Huntress has described a device code phishing attack dressed up as a Microsoft Teams meeting booking, Help Net Security reports. The target was an employee at a construction company.

How the trick works

Microsoft's device code sign-in lets you log in on one device by typing a short code on another. The attacker starts such a sign-in, receives a code, and shows it to the victim on a lure page labeled as a booking reference. When the victim enters that code on Microsoft's genuine login page, they unknowingly approve the attacker's session. The attacker then gets valid tokens for the victim's account.

The lure arrived by email from a lookalike domain impersonating a senior vice president at another construction firm, with a Google share link that redirected to the lure page.

Built to evade

  • The phishing page was encrypted and decrypted itself in the browser, which defeats scanners that don't run JavaScript.
  • If Microsoft returned an error, the kit quietly started a fresh device code session.
  • The final login came through a residential proxy to look like ordinary home traffic.

Because the victim signs in on the real Microsoft page, the usual advice to check the web address doesn't help here. The safer habit is to never enter a sign-in code you didn't request yourself.

Who's affected

Microsoft 365 users, particularly in industries like construction where meetings with outside contacts are routine.

What to do

Be suspicious of any request to enter a code on Microsoft's device login page that you didn't start. Admins should block or limit device code sign-in with conditional access where it isn't needed and use phishing-resistant MFA.
