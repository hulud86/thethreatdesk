# The Threat Desk

Source for https://thethreatdesk.com, a cybersecurity news site. Static HTML served by GitHub Pages.

- `index.html`, `stories.js`, `quiz.js`: front page
- `posts.json`: every published post; `build.js` generates the `<slug>.html` pages and `archive.html` from it
- `sitemap.xml`, `robots.txt`, `CNAME`: search and domain settings
